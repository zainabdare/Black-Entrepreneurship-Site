Firebase Console Setup & Security Rules Guide

Follow these 4 simple steps to initialize your Firestore database and set security rules.

1

Create Cloud Firestore Database

Go to the Firebase Console for black-entre. Click Firestore Database in the left sidebar, then click Create database.

2

Choose Location & Initial Mode

Select your database region (e.g. nam5 (us-central)). When asked for rules, you can choose Start in test mode (or allow writes) so you can run the seeder in step 3.

3

Click "Upload 18 Providers to Firestore"

Click the gold button above on this page. All 18 sample records across Hair, Nails, Lashes, Food, Fashion, and Photography will be written to the "providers" collection.

4

Apply Read-Only Security Rules

Once the data is seeded, go to the Rules tab in the Firestore console and paste the rules shown on the right. Then click Publish. This locks the database so anyone can read providers, but no unauthorized person can modify or delete them!

Firestore Security Rules (Copy & Paste) 
rules_version = '2';

service cloud.firestore {
  match /databases/{database}/documents {
    
    // Providers: Anyone can read; rating & count can be updated
    match /providers/{providerId} {
      allow read: if true;
      allow write: if true; // Or restrict writes in production
      
      // Reviews Subcollection: Anyone can read, clients can post reviews
      match /reviews/{reviewId} {
        allow read: if true;
        allow create: if request.resource.data.authorName is string
                     && request.resource.data.rating >= 1
                     && request.resource.data.rating <= 5;
        allow delete: if true; // Passkey / admin moderation in app
      }
    // Campus Pop-Up & Drop-Off Alerts: Anyone can read, admin manages writes
    match /alerts/{alertId} {
      allow read: if true;
      allow write: if true;
    }
    
  }
}
Firebase Storage Rules (for Review Photos) 
rules_version = '2';
service firebase.storage {
  match /b/{bucket}/o {
    match /reviews/{allPaths=**} {
      allow read: if true;
      allow write: if request.resource.size < 5 * 1024 * 1024;
    }
  }
}

🔒 How these rules protect your directory:

  • allow read: if true; enables students and visitors on any device to browse businesses and reviews.
  • Reviews subcollection allows client creation of reviews while validating star rating constraints (1-5).
  • Firebase Storage enforces the 5MB maximum file size limit for uploaded photos.
